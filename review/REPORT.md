# Отчёт независимого аудита CardFlow 1.0.0

**Снимок кода:** `53ead19` (ветка `main`, рабочее дерево чистое, кроме неотслеживаемых `PROGRESS*.md`, `TASK.txt`)
**Платформа аудита:** Windows 11, сборка `flutter build windows --release` из этого снимка (собрана заново 22.11.2026, 106,7 с)
**Flutter:** 3.47.9 (FVM), DPI монитора 150 % (devicePixelRatio = 1.5)
**Дата:** 22.11.2026
**Аудитор:** независимый ревьюер (не участник команды). Код не правился; запись только в `review/`.

---

## 1. Краткий вердикт: **НЕ ГОТОВО**

Приложение имеет зрелый каркас (единая дизайн-система, 2546 зелёных тестов, `flutter analyze` — 0 замечаний, аккуратные токены, локализация, реальные сценарии работают), но в текущем виде выпускать его нельзя. Ниже — причины, по которым вердикт «НЕ ГОТОВО», а не «УСЛОВНО ГОТОВО»:

1. **Оценка ставится до показа ответа** (`review_session_screen.dart:457`, `practice_session_screen.dart:341`). Пользователь может нажать «Знаю» на нераскрытой карточке — и система запишет оценку в FSRS. Это порча ядра продукта: расписание повторений строится по ответам, которых пользователь не видел. Проверено на живом приложении (`study_04_front.png` → `study_11_rated_without_reveal.png`: «Карточка 1 из 61 / Оценено: 0» сменилось на «Карточка 2 из 61 / Оценено: 1» без раскрытия).
2. **Создать карточку типа «С пропусками» без чтения исходников невозможно.** Синтаксис `{{c1::ответ}}` нигде не описан; естественная попытка `{{ответ}}` даёт ошибку «Добавьте хотя бы один пропуск» без подсказки о формате (`cardform_09_cloze_error.png`). Абсолютный тупик для нового пользователя.
3. **Экран «ИИ-генерация» не имеет постоянного выхода.** Панель приложения отсутствует, единственная стрелка «назад» уезжает вместе с прокруткой вверх, `Esc` не работает (`generation_03_esc_noop.png`). В нижней части длинной формы выхода с экрана нет вообще.
4. **Кнопка исправления критической ошибки нечитаема:** ссылка «Открыть настройки» в красном баннере «Сервер не настроен» имеет контраст **1,36:1** (измерено по пикселям: `#3525CD` на `#B6103B`). Это единственный путь исправления ошибки на этом экране.
5. **Редактор карточки теряет правки без предупреждения** — у `card_form_screen.dart` нет `PopScope`/подтверждения; стрелка «назад» молча выбрасывает введённый текст (`cardform_04_unsaved_discarded.png`).
6. **На разрешении 800×600 экран карточки обрезан:** ответ карточки перекрыт панелью оценок, текст читается не полностью (`study_10_classic_revealed_800x600.png`). Это одно из четырёх обязательных разрешений аудита.

Дополнительно: графики статистики нечитаемы (столбики шириной 153 px превращаются в «кляксы»), подписи метрик противоречат друг другу («Готовы к тесту» для «к повторению», «Просроченные» для «срок наступил»), в списке карточек видны сырые `{{c1::…}}`.

## 2. Что проверялось и как

**Метод.** Приложение запускалось как обычный пользователь (`cardflow.exe`, release), проходились все доступные экраны и диалоги; нажатия и ввод выполнялись через Win32 (реальные клики/клавиатура), снимки — `PrintWindow`, окно программно приводилось к клиентским размерам 1920×1080, 1366×768, 1024×768, 800×600 физических пикселей. Состояние приложения подтверждалось снимками, а не догадками.

**Данные.** Аудит шёл в двух профилях:
* реальный профиль владельца (13 колод, 377 карточек) — для навигации и дизайна; перед экспериментами данные скопированы, в конце восстановлены и сверены пиксельно-идентичным снимком (`decks_1920x1080.png` ≡ `verify_restored_data.png`, sha256 `604c5c98…`). В реальном профиле была поставлена и сразу отменена **одна** оценка (проверка undo); инструментально наличие следа в `review_logs` не проверялось — файл БД после восстановления не изменялся (mtime 20:46, WAL отсутствует), но гарантировать отсутствие одной записи журнала нельзя. Все остальные записи (колоды, карточки, оценки, удаления) выполнялись в одноразовом профиле;
* одноразовый профиль (пустая БД) — для записи, создания колод/карточек, сессий. Реальная база возвращена на место, число медиафайлов совпало (311).

**Прогоны.** `flutter test --no-pub --exclude-tags golden` → **2546 passed, 16 skipped, exit 0** (3 мин 43 с). `flutter analyze --no-pub` → **No issues found!** (89,5 с).

**Ограничения (честно):**
* **Реальная ИИ-генерация не запускалась.** У владельца настроен рабочий ключ DeepSeek (219 613 токенов за неделю), прогон потратил бы его деньги. Проверены только формы, состояния ошибок и предупреждения экрана генерации; предпросмотр генерации (`generation_preview_screen.dart`) не открывался — он недостижим без сетевого вызова. Сценарий «генерация → предпросмотр → импорт карточек» **не проверен**.
* **Импорт ZIP не доводился до конца** — проверен только системный выбор файла и отмена (`import_01_picker.png`, `import_02_cancelled.png`); нужного `.zip` в окружении не было, а создавать его в чужом профиле не стал.
* **Android-специфика** (системная кнопка «назад», свайпы) не проверялась: Android SDK на хосте отсутствует. Сделан вывод по коду (`PopScope`), а не по устройству.
* **Реальные свайпы** (лента, «Верно/Неверно») не выполнялись — только клики; поведение свайпов описано по коду (`feed_swipe.dart`) и подписям.
* **Экран «Тест»** не проверен: с 6 карточками во временном профиле он оставался недоступен («Мало подходящих карточек»), а требования к его разблокировке интерфейс не сообщает (`deck_10_modes_mixed.png`).
* **Режим «Подбор пар»** не проверен по той же причине (нужно ≥ 6 подходящих карточек, у меня не набралось).
* **Golden-тесты и шрифты на ОС** не проверялись (тег `golden` исключён; генерация golden — прерогатива Linux CI).

## 4. Оценки (10-балльная шкала)

| Критерий | Оценка | Обоснование |
|---|---|---|
| Дизайн (визуальное качество) | **5** | Хорошие токены, аккуратные карточки и тени, но: карточка сессии занимает 17 % экрана, обрезание на 800×600, «кляксы» графиков, дубли и противоречивые подписи |

Кнопки оценок: 4 колонки по 153 лог. px при ширине 640 (зазор 12), высота ≈ 56 лог. px (112 физ.) — ориентир 44 px соблюдён. При ширине < 520 лог. px — сетка 2×2 (видно на 800×600).
