# ADR-054 — заморозка метрики исхода, правило выбора пути, слепая выборка

**Статус:** принято (2026-11-28, срез 17 генерации v3). **Контекст:** срезы
13–16 сравнивали пути на несопоставимых величинах. `cleanRate` менял
знаменатель трижды (`accepted` → `generated` → `attempted`), `dupRate` у путей
означал разное (legacy — удалённый точный дубль, v3 — отложенный смысловой), а
человеческая оценка карточек не проводилась вовсе: числа сравнивались сами с
собой. TASK среза 17 требует последнюю правку определений, offline-дубль для
legacy, слепую человеческую выборку 30 + 30 и правило выбора пути, выведенное
числами, а не флагом в настройках.

## Решение

1. **Метрика заморожена** (`lib/domain/generation/outcome_counts.dart`,
   `lib/domain/generation/path_rule.dart`). Четыре величины, каждая отвечает на
   один вопрос и не входит в другую:
   - `acceptanceRate = accepted / attempted` — сколько попыток дошло до колоды;
   - `blockRate = blocked / attempted` — сколько отсек жёсткий гейт;
   - `cleanRate = clean / unique` — качество **сохранённой** карточки;
   - `dupRate = duplicates / unique` — доля сохранённого, оказавшегося повтором.
   `GenerationReport.cleanRate`/`duplicateRate` делегируют этим определениям
   (историческое `clean/generated` среза 13 в живом коде не остаётся). Дубль не
   двигает `cleanRate` — это записано тестом `outcome_counts_test`.
   **Смена любого определения — только новым ADR с явным «почему прежнее
   неверно»** (TASK п. 4). Доли, сохранённые в старых `cells/*.json`, при
   пересчёте не используются: считаются из счётчиков.
2. **Сопоставимость объёма.** `absoluteClean` сравнивается только при
   отношении принятых ≥ `kComparableVolumeThreshold = 0.8`; иначе строка
   помечается `volume_mismatch` и в критерий не идёт (TASK п. 3).
3. **Правило выбора пути — функция от материала, а не флаг.**
   `GenerationPathMode { auto, v3, legacy }` в `app_settings`
   (`generation_path_mode`, старый `generation_pipeline_v3` читается: `true` →
   `v3`, `false` → `legacy`), решение — `selectGenerationPath` с порогом
   `kGenerationPathV3MinUnits`. Порог N* выводится из оплаченных ячеек
   (`derivePathThreshold`): v3 выигрывает, если одновременно `cleanRate` не
   ниже, `dupRate` не выше и `absoluteClean` не ниже legacy.
   **По данным среза 17 разрыва нет** (материалы 10 и 33 единицы: v3 ниже по
   объёму чистых на 4 из 4 сопоставимых пар, по `dupRate` хуже на учебном
   тексте до 51 %), поэтому `kGenerationPathV3MinUnits = null`, авто остаётся
   legacy, а решение несёт флаг `boundaryNotDetermined` — «на границе выбор не
   определён данными». v3 доступен ручным переопределением режима.
4. **Слепая выборка — из сохранённого.** `buildBlindSample`
   (`lib/domain/generation/blind_sample.dart`) берёт 30 карточек на путь,
   перемешивает seed-ом, в файле выборки оставляет только номер и тексты, а
   ключ «номер → путь/ячейка/индекс» пишет отдельным файлом
   `blind-key-17.json` (открывать после заполнения). Новых платных прогонов для
   выборки не делается. Стенд (`S12Bench`) с среза 17 пишет карточки ячейки
   ключом `cards` — из них выборка строится без запросов.
   У ячеек до среза 17 текстов карточек нет, поэтому первая выборка —
   `not_measured` с причиной в файлах, а не выдуманные карточки.

## Следствия

- Критерий включения v3 больше не «cleanRate ≥ 95 %» (он был выведен из
  несопоставимых баз): решение — правило от объёма материала, и пока данных для
  N* нет, авто = legacy. Включение v3 по умолчанию требует нового замера с
  сохранёнными карточками и разрывом в данных.
- Дубли перестают штрафовать качество дважды: их доля — отдельная величина, а
  в задачу промпта (`gen-cards-v3`, S18) уходит именно она.
- Человеческая оценка становится измеримой: файл выборки и ключ собираются
  детерминированно, повторный замер даёт новый файл без ручной рулетки.

## Ограничения

- L235: N* не определён данными (два материала, один провайдер).
- L236: решение о пути принимается по режиму настройки; объём материала до
  Understanding неизвестен, поэтому при появлении N* его должен передать
  вызывающий слой.
- L237: слепая выборка среза 17 — `not_measured`: сохранённых текстов карточек
  нет, а платные прогоны срез 17 не делает.
