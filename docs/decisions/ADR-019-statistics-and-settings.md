# ADR-019 — Статистика и настройки (итерация 7)

**Дата:** 2026-11-14 · **Статус:** принято · **SPEC:** A6.1, A6.5, A6.6, A5, A7.2–A7.3, B2
**Контекст:** в итерации 7 нужен экран статистики (A6.5) и экран настроек (A6.6), а также оболочка
навигации (A6.1). Схема БД после первого релиза меняется только владельцем (SPEC 0.3 / промпт §5),
поэтому все пользовательские настройки должны уместиться в существующую `app_settings`. Спецификация
не задаёт точных формул статистики, дефолтов и способа «Проверить» ключ — эти развилки фиксируются здесь.

## 1. Хранение настроек

- Одна строка `app_settings` с ключом `app.settings` и JSON-значением `{"version": 1, ...}`
  (рядом с существующим `generation.openai_compatible` из ADR-013). Схема БД не меняется.
- `AppSettings` — неизменяемая доменная модель без Flutter; `fromJson` терпим к неизвестным ключам
  (совместимость вперёд), но отвергает неверные типы; числовые значения клампятся в допустимые
  диапазоны (битое значение не должно блокировать экран настроек).
- Битый JSON/неизвестная версия → **значения по умолчанию** (как `GenerationSettingsStore`, ADR-013),
  строка не удаляется: пользователь увидит дефолты и сможет записать корректные настройки.
- Запись — при изменении элемента настроек (контроллер), ошибка записи показывается сообщением из ARB;
  UI не притворяется, что сохранил.

**Дефолты (SPEC их не задаёт):** тема System, dynamic color выключен, motion Expressive, шрифт дислексии
выключен, масштаб текста 1.0, контраст обычный, haptics включён; desired retention 0.9 (как ADR-004),
шаги обучения 1 и 10 мин, лимиты 20 новых / 200 повторных (0 = без лимита), модель `gpt-4o-mini`.

## 2. Что именно меняют настройки (запрет мёртвых элементов)

| Настройка | Действие в приложении |
|---|---|
| Тема | `MaterialApp.themeMode` |
| Dynamic color | `DynamicColorBuilder`: системная схема, если платформа её даёт; иначе seed-схема (L6c — проверка на реальной ОС) |
| Контраст | `ColorScheme.fromSeed(contrastLevel: 1.0)` |
| Шрифт для дислексии | `fontFamily: 'OpenDyslexic'` в `ThemeData`; шрифт вложен в приложение (SIL OFL, §6) |
| Размер шрифта | `MediaQuery.textScaler` (0.8–1.4) в `MaterialApp.builder` |
| Анимация | «Выразительная» — пружина 380/0.8 и пульс Stories; «Стандартная» — пружина 700/0.9 и без пульса |
| Haptics | выключено — экраны классики/ленты не вызывают `HapticFeedback` |
| Желаемое удержание | `desiredRetention` у `FsrsScheduler` (ADR-004), влияет на интервалы и прогнозы кнопок |
| Шаги обучения | `learningSteps` у `FsrsScheduler` (1–5 шагов, 1–60 мин, возрастающие) |
| Дневные лимиты | `ReviewQueue.build(..., newLimit:, reviewLimit:)` в классике/ленте; конструктор не ограничивается (у него собственный лимит A6.7) |
| Модель по умолчанию | предвыбор провайдера/модели на экране генерации (A6.8), ключ и адрес — по-прежнему в существующих хранилищах |

Лимиты применяются к *очереди*, а не к записи оценок: уже начатая сессия досчитывает свой снимок.

## 3. Оболочка навигации A6.1

- `StatefulShellRoute.indexedStack` с тремя ветками: «Колоды» (`/`), «Статистика» (`/statistics`),
  «Настройки» (`/settings`); сессии, генерация, конструктор, форма карточки остаются полноэкранными
  маршрутами вне оболочки.
- Узкая раскладка (< 600 логических пикселей) — `NavigationBar`; широкая — `NavigationRail`.
- Пункт «Сессия» скрыт: активная сессия в текущей архитектуре — это полноэкранный маршрут, глобального
  состояния «активная сессия» вне его нет. Показывать пункт, ведущий в пустоту, запрещено (SPEC 3.6);
  при появлении глобальной активной сессии пункт включится (расширение без изменения контракта).
- Иконка настроек из AppBar «Колод» теперь ведёт в `/settings`; экран настроек генерации (ADR-013)
  открывается из блока «API» — единственная точка входа не теряется.

## 4. Семантика статистики A6.5

- **Удержание** — доля оценок `rating > 1` (Again = забыл) за последние 30 локальных дней; нет оценок —
  «нет данных» (не ноль и не 100 %).
- **Тепловая карта** — 365 локальных дней до сегодня включительно (год); цвет — интенсивность числа
  повторений в этот день.
- **Слабые темы** — теги карточек из `cards.tags_json`; тег слабый, если по его карточкам за 365 дней
  ≥ 5 оценок и доля Again ≥ 20 %; сортировка по доле Again убыванию, затем по числу ошибок, затем по
  тегу; показываем топ-5. «Тренировать» ведёт в конструктор с фильтром тега (`/constructor?tag=`),
  т.е. в существующий механизм A6.7 (ADR-018), без новой логики сессии.
- **Прогноз 7 дней** — карточки с `due` (не `new`, не `suspended`): просроченные (`due <= сейчас`)
  попадают в сегодня, остальные — в свой день; дни — локальные, 7 штук, начиная с сегодня.
- **Недельный прогресс** — число повторений за последние 7 дней (сегодня включительно).
- **Токены за неделю** — сумма `generation_jobs.tokens_used` за 7 дней (только расход, без ключей).
- Все агрегаты считает чистая `StatisticsCalculator`; drift-репозиторий только читает строки
  (`review_logs` за 365 дней, `cards.tags_json`, `cards.due`, `generation_jobs`). Схема не меняется.
- Графики — `CustomPainter` на токенах темы, без новых зависимостей (визуальный слой не тянет пакет
  ради трёх диаграмм; golden-тестов нет — L6).

## 5. Проверка ключа API («Проверить»)

- Минимальный синтетический запрос через **существующие** адаптеры и `GenerationHttpClient`
  (заголовки/адреса/формат — как у генерации), без записи `generation_jobs` и без карточек.
- Наружу — только `ApiKeyCheckStatus` (`valid`, `invalidKey`, `missingKey`, `noConnection`, `rateLimited`,
  `providerNotConfigured`, `unexpected`) → строка ARB. Тела ответов/ключи не логируются и в UI не попадают.
- Для OpenAI-совместимого сервера адрес/модель берутся из `app_settings` (ADR-013), ключ опционален.

## 6. Шрифт для дислексии

- `OpenDyslexic-Regular.otf` (SIL Open Font License 1.1) вкладывается в `assets/fonts/` вместе с
  `OFL.txt`; используется только при включённом переключателе. Вес — один Regular (остальные веса
  синтезируются Flutter); этого достаточно для читаемости, размер приложения +~176 КБ.
- Это осознанное исключение из «бинарные файлы не коммитим» (правило касается фикстур парсеров):
  шрифт — продуктовый ассет, без сети при первом запуске.

## 7. Последствия

- `app_settings` остаётся одной таблицей; миграций и `format_version` не требуется.
- Появляются новые экраны `/statistics` и `/settings`; прежний тест «иконка настроек открывает настройки
  генерации» заменяется тестом «иконка открывает настройки», а настройки генерации проверяются из блока API
  (изменение поведения по SPEC A6.1 фиксируется в журнале).
- Не проверено на реальной ОС: dynamic color (L6c), рендер OpenDyslexic и размеры на устройствах (L43),
  screen-reader статистики (L12), большие БД статистики (L44).
