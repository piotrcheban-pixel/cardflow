# ADR-045 — Дизайн-система v3: кобальт на графите, чистые кнопки оценки, единый чип фильтра

**Дата:** 2026-11-24 · **Итерация:** ui-ux-redesign · **Статус:** принято.
Дополняет и в части палитры/контролов заменяет [ADR-038](ADR-038-design-system-v2.md);
архитектура токенов ADR-038 сохраняется.

## Контекст

После редизайна v2 (ADR-038) палитра была построена вокруг indigo
`#3525CD` и голубоватых поверхностей `#E5EEFF/#DCE9FF`. На больших
плоскостях (сайдбар, панель колод, карточка) это читалось как фиолетовый фон,
что владелец явно отверг. В том же аудите зафиксированы три конкретных
дефекта интерфейса:

1. **Кнопки оценки** содержали цифры клавиш `1–4` и прогноз интервала
   («<1 мин», «6 мин», «16 д»); они отвлекали от решения «знаю/не знаю» и
   выглядели техническими. Владелец требует оставить только названия
   действий, сохранив расчёт интервалов внутри FSRS и работу клавиш 1–4.
2. **Чипы фильтра** («Все (13)» и т. д.) рисовались как `Text` внутри
   `Container(height: 38)` без выравнивания: при жёсткой высоте текст
   прижимался к верхней кромке, ряд выглядел съехавшим. Счётчик был частью
   строки, а не отдельным элементом.
3. **Анимации**: пульсация Stories и авто-продвижение ленты (3/5/8 с)
   работали бесконечно и не сообщали пользователю ничего полезного;
   длительность переворотов и панелей не была сведена к одной шкале.

## Решение

### 1. Палитра «кобальт на графите»

`app_tokens.dart` — единственное место цветовых литералов. Светлая тема:

| Роль | Значение | Комментарий |
|---|---|---|
| primary | `#1E4FD8` | кобальт; 6,7:1 с белым |
| onPrimary | `#FFFFFF` | |
| primaryContainer | `#D8E2FF` | |
| secondary / container | `#0F6B5C` / `#C9EFE6` | спокойный teal — «Легко», успех |
| tertiary / container | `#8A5300` / `#FFDF9E` | предупреждение/акцент |
| error / container | `#B3261E` / `#F9DEDC` | |
| surface | `#F6F7F9` | нейтральный графит без синего сдвига |
| surfaceContainerLow…Highest | `#F0F2F5…#D8DCE2` | |
| onSurface / variant | `#14181F` / `#4A5260` | |
| outline / variant | `#6E7683` / `#CDD2DA` | граница контрола ≥ 3:1 |

Тёмная тема: surface `#0B0E13`, контейнеры `#151A22…#2A3140`, primary
`#7FA5FF`, secondary `#5CD3BC`, error `#FFB4AB`. Акцент живёт в действиях,
состояниях и оценках, а не в фоне: крупные поверхности нейтральные.

Инвариант держит `test/guards/contrast_test.dart`: все пары «текст/фон»
(включая четыре оценки) ≥ 4,5:1, границы ≥ 3:1. Динамический цвет платформы
и режим повышенного контраста (ADR-019 §2) сохранены; при dynamic color
система остаётся той же, меняется только источник primary.

### 2. Кнопки оценки — только названия действий

`review_toolbar.dart`:

* подписи — `Не знаю / Затрудняюсь / Знаю / Легко` (`ratingHard` в ARB
  изменён с «Сложно»); цифры клавиш, прогнозы интервалов и обозначения FSRS
  из кнопок удалены;
* одна геометрия: высота 56 (compact — тот же 56, один ряд), кегль 18 с
  адаптивным множителем, текст по центру (`Center` + `TextAlign.center`),
  зазор ≥ 12;
* иерархия: единственная залитая кнопка — «Знаю» (primary/onPrimary);
  «Легко» — secondaryContainer; «Затрудняюсь» — нейтральная поверхность;
  «Не знаю» — тихая error-тонировка. Четыре кислотные плашки запрещены;
* состояния: hover (подсветка 8 % + граница оценки), pressed (16 %),
  focused (рамка 2 px onSurface), disabled (нейтральная заливка без акцента);
* **логика не менялась:** движок по-прежнему считает `preview`
  (`Scheduler.previewIntervals`) для каждой оценки и передаёт в FSRS ту же
  `Rating`; клавиши `1–4` работают (`session_keyboard.dart`), но не напечатаны.

Интервал-хелпер `review_interval_format.dart` удалён из UI-слоя: форматирование
для показа больше не нужно, значения остаются в домене и тестах планировщика.
Для тренировки интервалы не показывались и раньше.

### 3. `AppFilterChip` — единый фильтр

Новый `lib/ui/components/app_filter_chip.dart`:

* высота 36 + вертикальные поля 4 = цель нажатия 44; одинаковая у всех чипов;
* содержимое — `Row(mainAxisAlignment.center, mainAxisSize.min)`: `Flexible`
  подпись (ellipsis) + отдельный бейдж счётчика (`tabularFigures`), поэтому
  счётчик не сдвигает текст и не ломает ряд на узком экране;
* состояния selected (primary/onPrimary), unselected (surfaceContainerLow +
  outlineVariant), danger (error-текст и рамка), hover/pressed через `InkWell`,
  focused — стандартная рамка Material; disabled — приглушённый;
* счётчик — отдельный бейдж, а не «(13)» в строке. ARB-ключи
  `decksFilterAll/New/InProgress/Due` + `decksFilterMenuItem` (для меню в
  очень низком окне) заменили четыре `*Count`-строки.

Применён в ряду фильтров экрана «Колоды» (ключи `decks-filter-*`).
Многострочные чипы выбора колод в конструкторе остаются Material `FilterChip`
с темой приложения: у них другая роль (две строки названия колоды) и покрытие
`ChipTheme` уже задаёт общую высоту/цвета.

### 4. Движение

Единая шкала (`lib/ui/motion.dart` + `AppDurations`):

| Тип | Длительность |
|---|---|
| hover/pressed | 100–160 мс |
| смена состояния/чипа | 140–200 мс |
| появление панели/карточки | 180–260 мс |
| переворот карточки классики | 300 мс |
| полноэкранный переход ленты | 240 мс |

* удалены бесконечная пульсация Stories (`FeedProgressBar`) и таймер
  авто-продвижения ленты — постоянных анимаций в приложении больше нет;
* `AppMotion.reduce(context)` (системная настройка «уменьшить движение»)
  отключает анимации: длительности становятся `Duration.zero`, переходы ленты —
  `jumpToPage`, чипы/панели — без плавности;
* переключатель «Стандартная/Выразительная» из настроек больше не влияет на
  ленту (у неё нет пульса); классика использует `standard`-пружину без
  overshoot, выразительная — для переворота.

### 5. Типографика и пространство

Шкала ADR-038 сохранена (Inter, body 17, подписи ≥14, вопрос 32, ответ 24),
но в карточке ленты вопрос вырос до 28–46 в зависимости от окна, а ответ —
22–34: карточка остаётся главным объектом экрана. Минимальный реальный текст
в интерфейсе — 14,5 базовых (13 при масштабе 90 %), мелких кеглей нет.

## Последствия

* Контраст и палитра защищены guard-тестом; новые роли обязаны попасть в
  список пар.
* Изменение `ratingHard` («Сложно» → «Затрудняюсь») — пользовательский текст;
  тесты, ищущие подпись, используют `l10n.ratingHard`.
* Golden-тестов в проекте нет; визуальная приёмка — живое приложение и
  render-утилиты `review_final/`.
* Схема БД, домен FSRS, маршруты и настройки не менялись.
