# ADR-041 — Никаких синтезированных изображений в данных карточки

**Дата:** 2026-11-21 · **Итерация:** 7.19 «Изображения: диагностика и стороны» ·
**Статус:** принято.
Связано: SPEC A6.8/A8.1/A8.4; ADR-023/027/028/031/037; аудит
`journal/iteration-7.19/audit.md` §1–§4, §6.

## Контекст

Итерация 7.14 (ADR-031) добавила `PlaceholderImageGenerator`: при неудаче
привязки изображения рисовался детерминированный PNG (градиент, круги, полосы,
иконка вида) и **сохранялся как обычное медиа карточки** (`media`, файл,
`<path>.meta.json`, `isPlaceholder: true`). Владелец увидел на разных карточках
одинаковую абстрактную картинку с геометрическими фигурами и графиком.

Аудит 7.19 на фактической БД приложения: **80 из 207** медиа — заглушки,
68 из них `kind=diagram` («оси и столбики» — та самая картинка); у всех 80
непустой `query`, то есть это следствие неудачного внешнего поиска. Палитра
выбирается `contentHash % 8`, поэтому 15 визуальных групп покрывают 80
карточек (крупнейшая — 16). Промпт `gen-ru-v8` требовал изображение **у каждой**
карточки, что делало генерацию заглушек массовой. `main.dart` дополнительно
запускал фоновый `retryPlaceholders()`.

Дефект не является ошибкой сопоставления image id или общим fallback-asset:
это **маскировка ошибки** — отсутствующее или ненайденное изображение
подменялось содержательной на вид картинкой, которую нельзя отличить от
настоящей.

## Решение

### 1. Заглушка не может стать данными карточки

- `PlaceholderImageGenerator` удалён из кодовой базы; `GenerationPipeline`
  никогда не создаёт изображение.
- Неудачи привязки — **явные состояния**: `imageIdUnknown` (id вне каталога),
  `imageNotFound` (поиск не дал результата), отсутствующий файл, пустые байты,
  MIME не по сигнатуре (`imageInvalid`).
- Пустой слот в редакторе — нейтральная иконка и текст (ARB), не PNG; он не
  сохраняется, не передаётся модели, не входит в каталог `<images>` и не
  экспортируется как медиа.

### 2. Проверка байтов до записи

`lib/domain/generation/image_bytes.dart` определяет формат по сигнатуре
(JPEG/PNG/WebP; GIF не является изображением карточки). `DriftGenerationCardStore`
и `DriftCardRepository` отклоняют пустые/повреждённые байты и MIME, не
совпадающий с сигнатурой: строка `media` и файл не создаются.

### 3. Существующие заглушки удаляются

`PlaceholderMediaPurger` при старте (`main.dart`, до первого кадра) удаляет
строки `media` с `provider = placeholder` / `isPlaceholder = true`, их файлы и
`<path>.meta.json`, а также убирает id из `media_json` всех карточек (v2 и
legacy). Настоящие изображения не трогаются. Схема БД не меняется.

### 4. Ошибка отображения — не скелетон

`CardImageView` показывает явное состояние ошибки декодирования с кнопкой
повтора (`card-image-error`, `card-image-retry`); отсутствующий файл в
`CardContentView` — отдельное состояние «изображение недоступно» с повтором, а
не пустое место и не другая картинка.

### 5. Диагностика целостности

`MediaIntegrityChecker` проверяет цепочку «карточка → media-строка → файл →
байты → MIME», находит отсутствующие/пустые файлы, несовпадение MIME,
заглушки, чужого владельца и одинаковые байты у разных карточек; отчёт не
содержит бинарных данных. CLI — `tool/media_integrity_report.dart`.

## Последствия

- Ненайденная картинка больше не выглядит как найденная: карточка остаётся без
  изображения, в предпросмотре — предупреждение и пометка.
- Промпт v9 снимает требование «картинка у каждой карточки»; изображение —
  осознанный выбор модели (ADR-042).
- Заглушки из старых баз удаляются при первом запуске 7.19; ручной откат не
  предусмотрен (они не являются исходными изображениями).
- Фоновый ретрай заглушек удалён; «Найти картинку заново» в редакторе остаётся
  для настоящих изображений.
