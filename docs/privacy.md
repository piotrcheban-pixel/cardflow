# Политика приватности CardFlow

**Дата:** 2026-11-14 · **Приложение:** CardFlow 1.0.0

CardFlow — локальное приложение для интервального повторения. Разработчик не
запускает собственный сервер и не собирает аналитику: данные обучения остаются
на устройстве пользователя.

## Какие данные хранятся на устройстве

- колоды, карточки, теги, медиафайлы и настройки — в локальной базе SQLite и
  каталоге данных приложения;
- журнал повторений (`review_logs`) — оценки, время, режим;
- журнал заданий генерации (`generation_jobs`) — провайдер, модель, число
  токенов, версия промпта, имена файлов. Тексты материалов и ответов модели в
  журнал не пишутся.

## Ключи API

Ключи OpenAI, Gemini, Anthropic и OpenAI-совместимого сервера хранятся только
в защищённом хранилище платформы (`flutter_secure_storage`). Они не попадают в
базу, журналы, экспорт `.zip`, аналитику и репозиторий; в интерфейсе
показывается только факт наличия ключа.

## Сеть

CardFlow обращается в сеть только при явном действии пользователя:

- генерация карточек — запросы к выбранному провайдеру или указанному
  OpenAI-совместимому серверу с ключом пользователя;
- «Проверить» в настройках API — один минимальный запрос для проверки ключа;
- внешние ссылки (эта политика, лицензии, «Где взять ключ») открываются
  системным браузером.

Материалы прикреплённых файлов и пожелания отправляются только выбранному
провайдеру и только по нажатию кнопки генерации. Разработчик не получает и не
хранит эти данные.

## Экспорт и импорт

Экспортируется только колода, которую выбрал пользователь: карточки, медиа и
`meta.json`. Ключи API в архив не включаются.

## Удаление данных

Пользователь удаляет колоды, карточки и настройки в приложении; удаление
колоды удаляет её карточки и медиа. Полное удаление данных — удаление
приложения и его каталога данных средствами ОС.

## Дети и третьи стороны

Приложение не предназначено специально для детей и не передаёт данные третьим
сторонам, кроме выбранного пользователем API-провайдера (обработка запросов
регулируется политикой этого провайдера).

## Контакты

Вопросы: `agent@cardflow.local` (заглушка владельца; заменяется при публикации).
