# CardFlow — промпт продолжения сессии

Короткий промпт для каждой новой сессии после первой. Не пересказывайте историю — агент восстановит контекст из файлов.

## Вариант «ИТЕРАЦИИ» (по умолчанию)

```text
Продолжаем CardFlow. Автономность: ИТЕРАЦИИ.

1. Прочитай AGENTS.md, docs/agent-prompt.md, journal/STATE.md, план текущей итерации
   и нужные разделы SPEC.md.
2. Сверь STATE.md с реальностью: git status, git log --oneline -5, последний прогон
   тестов. Если расходятся — верь репозиторию, исправь STATE.md.
3. Выполни следующее действие из STATE.md и доведи текущую итерацию до шага 7
   включительно, не останавливаясь внутри итерации.
4. Отчёт: сделано, доказательства (команды и результат), что не проверено и почему,
   ADR итерации, открытые вопросы к владельцу, следующее действие. Затем стоп.
```

## Вариант «MVP» (автономный прогон)

```text
Продолжаем CardFlow. Автономность: MVP.

1. Прочитай AGENTS.md, docs/agent-prompt.md, journal/STATE.md, план текущей итерации
   и нужные разделы SPEC.md.
2. Сверь STATE.md с реальностью (git status, git log, последний прогон тестов);
   при расхождении верь репозиторию.
3. Продолжай с «Следующего действия» и иди до выполнения всех критериев остановки MVP
   (раздел 9 стартового промпта). Останавливайся только на внешнем блокере, требующем
   владельца, или после трёх неудачных заходов на одну проблему.
4. В конце каждого шага обновляй journal/STATE.md. По завершении MVP — итоговый отчёт
   со статусом каждого критерия и доказательствами.
```

## Если сессия оборвалась посреди шага

```text
Продолжаем CardFlow после обрыва. Прочитай journal/STATE.md и последний коммит,
проверь git status: возможно, остались незакоммиченные изменения. Установи, на каком
шаге цикла остановились, и продолжи с него. Не начинай итерацию заново и не откатывай
рабочее дерево без необходимости.
```
