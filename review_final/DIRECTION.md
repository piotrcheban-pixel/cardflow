# Визуальное направление CardFlow — «финальная доводка»

Сформулировано по итогам аудита `review_final/REPORT.md` (снимок `fbe344a`)
и задания «Финальная визуальная доводка».

## Формула направления

**Спокойный · премиальный · воздушный · точный · крупный.**

Пять прилагательных — один язык для всех экранов. «Спокойный» — один акцент,
тихие поверхности, никаких кислотных пятен. «Премиальный» — глубина через
тень и границы, а не через декор. «Воздушный» — 4/8-сетка, поля 24–40,
крупные объекты. «Точный» — всё из токенов, одна контентная колонка, ни одной
обрезанной подписи. «Крупный» — главный объект экрана занимает ≥60 % рабочей
области, основной текст 17–24, вопрос карточки 28–46.

## Принципы (держатся на каждом экране)

1. **Одна контентная колонка.** Все страницы (колоды, колода, статистика,
   настройки, генерация, конструктор) используют одну адаптивную ширину
   `AppSizes.pageWidth(context)`: 1280 на FullHD, до 2600 на 4K. Формы — узкая
   колонка ≤ 720×(1…1,45) внутри этой ширины. Переход между экранами не
   сдвигает левую кромку контента.
2. **Иерархия сверху вниз.** Заголовок страницы — `displayLarge`
   (38 × адаптив) и всегда крупнее KPI. Секции — `titleLarge`, основной текст —
   `bodyLarge`, подписи — не мельче 14,5 базовых (≥13 после масштаба 90 %).
3. **Карточка — главный объект.** Ширина 72 % окна (≥60 %), высота не меньше
   62 % рабочей области. Содержимое распределено по высоте, самая большая
   сплошная пустая полоса ≤ 30 %. Вопрос ≥28 на 2K, ≥24 на FullHD; ответ ≥22/20.
4. **Один вход на действие.** Выход из сессии — один (крестик в шапке либо
   основная кнопка состояния, но не оба). Диалоги — один компонент
   `AppDialog`; у подтверждения либо «×», либо «Отмена», не оба.
5. **Семантика цвета.** Один акцент (индиго). Оценки — один тон-ряд:
   светлая тонировка + общая нейтральная граница, различие — цветом текста и
   подписи интервала; подписи интервалов — один вторичный цвет. Опасное
   действие — `error`, безопасное — `primary`.
6. **Поверхности.** Радиусы 10/12/16/20, границы интерактивных контролов —
   `outline` (≥3:1), тень карточек — мягкая (2 слоя), диалоги — 20 и затемнение
   45 %. Никаких «палевых» заглушек: изображения — contain, плитка по
   пропорции файла.
7. **Движение.** Три корзины: 120–160 (отклик), 200–250 (панель/шаг),
   280–350 (переворот/страница). Кривые `easeOutCubic`/`easeInOutCubic`.
   Reduced motion отключает всё, включая пружины, авто-прокрутку и чипы.
8. **Состояния — полноценные экраны.** «Завершено», «пусто», «время истекло»,
   «ошибка», «план не найден» — крупный смысловой центр (≥520 px ширины,
   hero-иконка, заголовок 30–38, метрика), одно основное действие. Загрузка —
   скелетон с геометрией контента, а не голый спиннер.

## Что не делаем

- Не добавляем новые функции, экраны, данные и бизнес-логику.
- Не показываем неактивные кнопки: недоступное действие скрыто.
- Не дублируем действия и не оставляем временных стилей.
- Не жертвуем контрастом и читаемостью ради эффектов.
