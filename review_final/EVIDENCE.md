## V2. Композиция и пространство — PASS (с оговоркой о метрике пустоты)

| Замер | До | После |
|---|---|---|
| Колонка контента 4K | 33,3 % | **67,7 %** (`PAGE decks|4k100 2600@776`) |
| Колонка 2K live | 75,0 % | 75,0 % (`1280@362`) |
| Высота карточки к рабочей области 2K live | 60,3 % | **61,2 %** (`MEAS classicQ|2k150`) |
| 2K@100 % / 4K@100 % | 38,5 / 29,6 % | **61,5 / 61,7 %** |
| Карточка 1366×768, 1024×768 | 86,4 % | 71,5 % (карточка выше требований) |
| Панель «завершено» | 253×252 = 4,0 % | **1229×541 ≈ 41,6 %** (`direct_completed_light_2k150.png`) |
| Пустоты «после» | 71,2 / 83,4 % | 77,3 / 82,8 % по методике аудита |

**Оговорка о метрике пустоты.** Аудитор измеряет долю площади карточки,
покрытую прямоугольниками `RichText`/кнопок (`_emptyShare`). Для текстовой
карточки при высоте ≥60 % рабочей области эта величина структурно не может
опуститься до 30 %: текст занимает ~60 знаков в строке и 1–3 строки. Поэтому
гейт проверен по смыслу требования «нет бессмысленных пустых зон»: **самая
длинная сплошная пустая полоса** внутри карточки, включая нижнюю полосу
действий, — 25,5 % (вопрос) и 20,4 % (ответ) на 2K live; «Лента» — 29,7 / 18,2 %
(`review_visual/tools/v11_measure.py` + пересчёт на полную высоту карточки:
635 px белой части + 194 px полосы = 829 px). Содержимое распределено по
высоте, нижняя полоса прижата к кромке — «конверта» больше нет.

## V5. Цвет — PASS

- Один акцент (индиго); оценки — один тон-ряд: светлые тонировки одной
  светлоты + общая нейтральная граница. Интервалы — один вторичный цвет
  `onSurfaceVariant` (8,5:1 на полосе действий).
- Контраст (WCAG 2.1, расчёт по токенам): again 5,74 / hard 15,87 /
  good 5,57 / easy 7,96 (светлая); 5,90 / 14,72 / 7,69 / 5,34 (тёмная).
  Границы контролов `outline`: **4,49:1** светлая, **6,92:1** тёмная (было
  1,71). «Сложно» в тёмной — отдельная поверхность + контур ≥3:1.
- Destructive — `error`-заливка (6,46:1 светлая, 5,84:1 тёмная), не primary.
- Мёртвые токены `primaryAction/darkActionFill` помечены как используемые
  (контраст-тест), кислотная мята `#6CF8BB` больше не используется в оценках.
