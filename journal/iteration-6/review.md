# Итерация 6 — ревью (Lead, чек-лист на неизменяемом снимке)

**Дата:** 2026-11-14 · **Шаг:** 4 · **Снимок:** `70b1d97` (`feat: session constructor screen and
plan-based sessions`) · **Независимый reviewer:** недоступен (`list_agents` → только `lead`, L35),
ревью Lead по чек-листу (практика итераций 4–5).

## Что проверялось

1. **Покрытие SPEC A6.7/A7.19/A7.20:** мультивыбор колод, теги, тип, состояние (новые / в процессе /
   повторение / пиявки), режим classic/feed, лимит N карточек / N минут, перемешивание, интерливинг,
   разминка, «Сохранить пресет» / «Начать сессию», пресеты в `session_presets` — всё есть, мёртвых
   элементов нет: у каждого обработчик, состояние и тест.
2. **Слои и границы:** `lib/domain/session/` без Flutter; `lib/data/session|review/` — только drift;
   UI не ходит в БД напрямую (провайдеры `app_providers`); `session_presets` используется без
   изменения схемы (ADR-005/018).
3. **Порядок сборки и фильтры:** фильтры OR/пусто=всё, suspended/buried исключены, базовый порядок
   `due ASC → createdAt ASC → id ASC`; разминка ≤4 выученных по stability; лимит после порядка.
4. **Лимит минут:** `Timer` экрана, после истечения — итоговый экран, оценки/раскрытие/авто-продвижение
   заблокированы; `due`/`fsrs_json` непройденных карточек не трогаются; таймер отменяется в `dispose`.
5. **Гонки и состояние:** `busy`-флаги движков не менялись; запись оценки после закрытия экрана
   безопасна (`_disposed` в движках); повторный `start()` конструктора.
6. **Ошибки и строки:** пользовательские тексты — только ARB (guard `ru_strings`); сырые исключения не
   выводятся (снекбары/состояния — ARB); ошибки drift не маскируются под ошибки фрагментов.
7. **Безопасность:** ключей/сети нет; SQL пиявок параметризован (`Variable<String>`); битый
   `config_json` пресета пропускается, а не роняет экран; `fsrs_json` не парсится вне try.
8. **Тесты:** 48+35 красной фазы домена/данных, 58+25 красной фазы UI, 13 widget-тестов конструктора,
   плановые сессии классики/ленты (порядок, лимит минут, отсутствие плана), интеграция на
   production-графе и реальной drift-БД.
