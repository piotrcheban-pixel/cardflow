# Итерация 3a — «Парсеры». Итог (шаг 6–7)

**Дата:** 2026-11-13 · **Режим:** `ИТЕРАЦИИ` · **Статус:** завершена (verify — `journal/iteration-3a/verify.md`)
**Цель (SPEC B2/A8.3):** нативный локальный парсинг PDF/DOCX/XLSX/PPTX/ODT/TXT/MD/RTF в нормализованный текст
с границами разделов и метаданными; кодировки; сканы; понятные ошибки по файлу; лимиты; `.doc/.xls` — ADR-003.

## Сделано

- **Домен** (`lib/domain/text/`): `DocumentFormat` + определение по расширению/сигнатурам, `ParsedDocument`
  (текст + `ParsedSection.start/end/title` + метаданные, инварианты, immutable), `ParserErrorCode`/
  `ParserException`, единый `normalizeDocumentText` (CRLF, control-символы, NBSP, пустые строки, trim).
- **Парсеры** (`lib/api/parsers/`): DOCX (абзацы/таблицы/заголовки, tab-stops игнорируются, `w:sdt`/
  `w:customXml` разворачиваются), PPTX (порядок `presentation.xml` + fallback), ODT (заголовки/абзацы,
  оглавление/аннотации пропускаются), XLSX (`excel_plus`, листы→разделы, кэш формул, `=формула` без кэша,
  даты `yyyy-MM-dd`, ZIP-лимиты), TXT/MD (BOM/UTF-8/cp1251/KOI8-R по частотной оценке), RTF (минимальный
  конвертер: cp1251/1252/KOI8-R/U, `\uN`+`\uc` в группах, `\*`/служебные группы, control symbols), PDF
  (`pdfrx`/PDFium в изоляте: текстовый слой, скан, битый, запароленный; страницы→разделы).
- **Сервис** `FileParsingService`: лимит 25 МБ, сигнатуры, реестр парсеров, `Isolate.run` (инжектируемый
  `IsolateRunner`), ошибка файла не блокирует остальные, сырые исключения/`details` не утекают.
- **UI-контракт ошибок:** `parserErrorCodeMessage`/`parserErrorMessage` → 5 строк ARB; guard `ru_strings` зелёный.
- **Документация:** ADR-010 (+дополнения fix-итерации), `docs/parsers.md`, `docs/dependencies.md` §9–§10.

- **ADR-010** — формат `ParsedDocument`/границы разделов, единая нормализация, коды ошибок, детекция
  форматов и строгие сигнатуры, лимиты (25 МБ; ZIP: 10 000 записей/32 МБ запись/120 МБ сумма) для всех
  4 ZIP-форматов включая XLSX, определение кодировок TXT/MD, RTF-конвертер (cp1251/1252/KOI8-R/U, `\uc` в
  группах, `\*`-группы), PDF через pdfrx в изоляте, изоляция ошибок по файлам; дополнения fix-итерации —
  разделитель `\n\n`, immutable-модели, DOCX/ODT/XLSX/PDF уточнения.

## Улучшение процесса (шаг 7, ретроспектива)

1. **Спайк до плана сработал:** 5 спайков (S-ENC/S-OOXML/S-XLSX/S-PDF/S-PDF-isolate) сняли главные риски
   (pdfrx в изоляте, cachedValue, `innerText`) до написания тестов — не было переделок архитектуры.
2. **Независимое ревью на снимке** дало 2 high (RTF `\*`, XLSX ZIP-лимиты), которые не видны в unit-тестах
   «своего» кода; фикс-итерация закрыта отдельным коммитом, каждый пункт — новым тестом/фикстурой
   (включая программный запароленный PDF V1/R2 RC4 40-bit). Правило «фиксы фиксируются тестом» — в AGENTS.
3. **Замедлило:** большой объём кода/тестов в одной итерации (23 production-файла); в следующих итерациях
   делить парсеры на 2 коммита по форматам (уже применено: OOXML отдельно, остальные отдельно).
