`fvm flutter build windows --release --no-pub`), окно приведено к логическому
размеру 1440×900 (физический 2160×1382 при масштабе Windows 150%) и 390×844
(физический 585×1298). Снимки — в `journal/redesign/screenshots/`, сняты с
реальной локальной БД приложения (данные владельца, вне репозитория не
публикуются). Сравнение — с `redesign/2` (v2) и снимками `r2-*.png`; для
мобильного ориентир — `r1-mobile.png` и классы `lg:`.

## Осознанные отступления от макета

1. **Словарь оценок.** SPEC A7.2 задаёт «Не знаю / Сложно / Знаю / Легко», а
   макет — «Снова / Трудно / Хорошо / Легко». Продуктовая истина — SPEC и код
   (`Rating`), поэтому подписи макета не переносятся; цвета, раскладка,
   прогноз интервалов и клавиши — по макету.
2. **«Синхронизировано», профиль, серия в шапке.** В CardFlow нет
   синхронизации и учётной записи; фиктивные индикаторы запрещены (SPEC 3.6).
   В шапке — крошки, «Новая карточка» (реальный выбор колоды) и настройки; в
   панели — реальный остаток повторений.
3. **Pushed-экраны** (форма карточки, конструктор, провайдеры, предпросмотр)
   сохраняют `AppBar` темы дизайн-системы: им нужен возврат, сайдбара на них
   нет. Основные экраны — `AppPageHeader` без `AppBar`.
4. **ИИ-генерация — полноэкранный маршрут** `/generate` вне оболочки
   `StatefulShellRoute`: сайдбар на нём не рисуется (архитектура маршрутов),
   композиция формы повторяет макет.
5. **Блоки «Данные», «Учётная запись», «Синхронизация»** из макета не
   переносятся: в приложении нет соответствующих функций, мёртвые экраны
   запрещены.
6. **Дополнительный пункт «Конструктор»** в панели: реальный маршрут
   `/constructor`, в макете его нет.

## Ограничения

- Экран хоста 2560×1440 при масштабе 150%; «физические» 1440×900 достигаются
  окном 2160×1382. Снимки приведены к логическим размерам.
- Пиксельного diff-инструмента в окружении нет: сравнение — визуальное по
  снимкам (структура, пропорции, цвета, типографика, отступы).
- Golden-тесты не используются: в проекте нет golden-инфраструктуры с
  кириллическими шрифтами на Windows (golden-тег — Linux CI).
- Android/iOS-сборки недоступны (нет SDK в окружении, L1).
