# Ревью итерации 7.8 — вложения и Vision (2026-11-15)

Снимок: рабочее дерево до коммита зелёной фазы (L35: независимый reviewer в сессии недоступен, ревью Lead по
чек-листу на неизменяемом снимке после полного зелёного прогона).

## Чек-лист

| № | Проверка | Результат |
|---|---|---|
| 1 | Секреты: ключи не в коде/логах/ошибке | `providerReason` очищается от `sk-…`, `AIza…`, `Bearer …`; тела не логируются; `ApiKeyStore` не тронут |
| 2 | Сырые ошибки API в UI | Исключение — `providerReason` (ADR-022 §5, требование владельца); `details`/стектрейсы по-прежнему не показываются |
| 3 | Локаль ru, строки из ARB | Новые строки только в `app_ru.arb`; guard `ru_strings` зелёный; allow-list дополнен форматами JPG/JPEG/PNG |
| 4 | Нет WebView/HTML | Не добавлено зависимостей; guard `no_webview` зелёный |
| 5 | Домен без Flutter | `text_sanitizer.dart`, `generation_attachment.dart` — только `dart:typed_data`; guard `architecture` зелёный |
| 6 | Схема БД | Не менялась; `app_settings`/`generation.providers` получил `supports_vision` (JSON v1), миграция читает старые записи |
| 7 | Стык слоёв | Интеграционный тест production-графа: OpenAI `gpt-4o` + PNG → `image_url` data URI + `job.files`; DeepSeek + PNG → `visionUnsupported`, HTTP 0 |
| 8 | Ошибка файла не блокирует остальные | Вложения — отдельные фрагменты; ошибка одного фрагмента → partial/повтор (pipeline-тесты) |
| 9 | Повтор упавших | `GenerationChunkFailure.images` сохраняются и передаются в `retryFailed` (тест) |
| 10 | Пустой текст не ходит в сеть | `_validateAttachments`/`noMaterials` до адаптера/транспорта (тест `transport.calls == 0`) |
| 11 | Любая модель | Текстовый путь не требует Vision; текстовые модели получают текст без изменений |
| 12 | Русский UI | Сообщения: «Модель не поддерживает изображения», «PDF-скан не поддерживается выбранной моделью», «Файл больше 10 МБ…» |

## Находки и фиксы (fix-коммит)

| # | Находка | Severity | Фикс |
|---|---|---|---|
| M1 | Anthropic PDF-документ требует beta-заголовок `anthropic-beta: pdfs-2024-09-25`; без него PDF-скан мог быть отклонён | medium | `AnthropicAdapter` добавляет заголовок только при PDF-вложении; тест |
| M2 | Причина 400 могла попасть в сообщение для 5xx/401/429, где у нас свои строки | medium | `providerReason` присваивается только в финальной ветке `badRequest`; HTML/мусор → `null`; тесты |
| M3 | Сначала проверялся размер, потом Vision: у текстовой модели с большой картинкой пользователь видел «файл большой» вместо «модель не поддерживает изображения» | medium | Vision-проверка первой; тест «причина нет изображений важнее размера» |
| M4 | `source_excerpt` сверялся с несанитизированным `request.materialsText` (NUL мог ломать сравнение) | medium | `contentValidator` получает санитизированный `materialsText` |
| L1 | UI блокирует всю генерацию, если приложен скан и у модели нет Vision, даже когда есть текстовые документы | low | Осознанно: требование «vision=false + картинка → ошибка» (owner note); сообщение понятное |
| L2 | `providerReason` может быть на английском (например, `invalid characters in content`) | low | Требование владельца показывать реальную причину; ADR-022 §5 |
| L3 | Реальный DnD изображения на ОС не проверялся | low | L56; путь идёт через тот же `DropTarget`/picker |
| L4 | Инференс Vision по имени модели — эвристика | low | L54; переключатель в настройках |

Блокеров/critical/high нет. M1–M4 закрыты в коде этой итерации с тестами; отдельных fix-коммитов
не потребовалось, потому что находки исправлены до коммита зелёной фазы (снимок ещё не был
зафиксирован независимым ревьюером).
