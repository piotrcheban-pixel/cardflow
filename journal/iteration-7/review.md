## Что проверено

- SPEC A6.1: оболочка (`NavigationBar`/`NavigationRail`, ветки, скрытая «Сессия»), маршруты и переходы.
- SPEC A6.5: блоки статистики, формулы (30 дней/год/неделя/прогноз/слабые темы), пусто/ошибка.
- SPEC A6.6: все блоки настроек, реальное действие каждого элемента, сохранение в `app_settings`,
  ошибки записи, API-проверка, «О приложении».
- ADR-019: хранение, семантика, оболочка, проверка ключа, шрифт, ограничения (L43–L46).
- Безопасность: ключи только secure storage/заголовки; проверка ключа не пишет `generation_jobs`,
  не логирует тела/ключи; `no_secrets`; сырые исключения в UI не попадают.
- Архитектура: domain без Flutter; M3E только через `lib/ui/m3e/`; Material — `material_ui`;
  схема БД не менялась (`schemaVersion = 1`, миграций нет); статистика — только чтение.
- Тесты: полный прогон 1171+1, integration на реальной drift-БД и production-провайдерах.

- Ключи не попадают в `AppSettings`, БД, логи, экспорт; `ApiKeyVerifier` передаёт ключ только в заголовок

- `docs/privacy.md` описывает локальные данные, ключи, сетевые вызовы и экспорт.
