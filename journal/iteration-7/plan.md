# Итерация 7 — «Статистика + настройки»: план

**Дата:** 2026-11-14 · **Режим:** ИТЕРАЦИИ · **Снимок старта:** `b2293cc` (origin/main, CI success
[43618351413](https://github.com/piotrcheban-pixel/cardflow/actions/runs/43618351413))
**SPEC:** A6.1 (навигация), A6.5 (статистика), A6.6 (настройки), B2 (итерация 7), A4 (токены),
A5 (`app_settings`, `review_logs`, `generation_jobs` — схема не меняется), A7.2/A7.3 (haptics/motion),
ADR-004 (FSRS), ADR-008 (порядок очереди), ADR-018 (конструктор, теги).

## Цель итерации (вертикальный срез)

Пользователь видит реальную статистику обучения (удержание, годовая тепловая карта, слабые темы с
переходом в конструктор с фильтром тега, прогноз 7 дней, недельный прогресс) и управляет приложением
с экрана настроек: тема/цвет/шрифт/размер/контраст, API-ключи и модель по умолчанию, желаемое удержание,
шаги обучения и дневные лимиты, haptics, «О приложении». Настройки сохраняются в `app_settings`
и **влияют на поведение**, а не только хранятся. Появляется оболочка A6.1: `NavigationBar` на телефоне,
`NavigationRail` на планшете/ПК.

## Задачи, файлы, проверка

### 1. Домен настроек (TDD, red → green)

- `lib/domain/settings/app_settings.dart`: `AppThemePreference`, `MotionPreference`, `AppSettings`
  (тема, dynamic color, motion, шрифт дислексии, масштаб текста 0.8–1.4, контраст, haptics,
  desired retention 0.70–0.95, шаги обучения 1–5 шт. (1–60 мин), дневные лимиты новых/повторных
  (0 = без лимита), провайдер и модель по умолчанию), JSON `version=1`, `copyWith`, валидация/клампы,
  неизвестные ключи игнорируются.
- `lib/domain/settings/app_settings_store.dart`: порт `read()/write()`.
- `lib/data/settings/drift_app_settings_store.dart`: одна строка `app_settings` c ключом
  `app.settings`; битый JSON → значения по умолчанию (как `GenerationSettingsStore`, ADR-013).
- `lib/ui/state/app_settings_providers.dart`: `appSettingsStoreProvider`, `AppSettingsController`
  (AsyncNotifier: state сразу, запись в store; ошибка записи — исключение для UI), `effectiveAppSettings`
  (значения по умолчанию до загрузки/при ошибке), `weeklyTokenUsageProvider`.
- Проверка: unit-тесты JSON (roundtrip, клампы, версия, битые типы), store на реальной drift-БД
  (read/write/битая строка/дефолт), контроллер (обновление + ошибка store).

### 2. Домен и данные статистики (TDD, red → green)

- `lib/domain/statistics/statistics.dart`: `ReviewSample` (cardId, rating, reviewedAt),
  `StatisticsSnapshot` (`totalReviews`, `retention30` (доля оценок > Again за 30 дней),
  `heatmap` — 365 локальных дней, `week` — 7 дней, `weakTopics` — теги с ≥5 повторами и долей
  Again ≥ 20 % (топ-5), `forecast` — 7 дней (просроченные → сегодня), `tokensWeek`),
  `StatisticsCalculator.build(...)` — чистая функция, `clock` снаружи.
- `lib/domain/statistics/statistics_repository.dart`: порт `load({required DateTime now})`,
  `tokensUsedSince(DateTime)`.
- `lib/data/statistics/drift_statistics_repository.dart`: SQL за 365 дней по `review_logs`,
  теги карточек (`tags_json`), `cards.due` (state != new, suspended = 0), сумма
  `generation_jobs.tokens_used` за 7 дней; разбор тегов терпим к битому JSON.
- Проверка: unit-тесты калькулятора (границы 30/365/7 дней, пустые данные, порог слабых тем,
  просроченные → сегодня, порядок), data-тесты на реальной drift-БД (посев строк, все блоки,
  битый `tags_json`, пустая БД).

### 3. Оболочка A6.1 и маршруты

- `lib/ui/shell/app_shell.dart`: `NavigationBar` (ширина < 600) / `NavigationRail` (≥ 600) с пунктами
  «Колоды», «Статистика», «Настройки»; «Сессия» скрыта: активной сессии вне полноэкранного маршрута
  нет (ADR-019).
- `lib/ui/router/app_router.dart`: `StatefulShellRoute.indexedStack` с тремя ветками
  (`/`, `/statistics`, `/settings`); остальные маршруты — вне оболочки; настройки генерации остаются
  отдельным маршрутом `/settings/generation`.
- Экран колод: иконка настроек ведёт в `/settings` (генерация — из блока API настроек).
- Проверка: widget-тесты оболочки (узкая/широкая ширина, переключение ветки, состояние ветки),
  router-тест (ветки и пути), app-тесты (навигация из «Колод» в «Статистику»/«Настройки»).

### 4. Экран «Статистика» A6.5

- `lib/ui/statistics/statistics_screen.dart`: состояния loading / error / empty / data; блоки:
  удержание (большая цифра + waveform `CustomPaint`), тепловая карта года (CustomPaint, подписи месяцев),
  недельный прогресс (waveform), прогноз 7 дней (столбцы с подписями дней), слабые темы
  (тег, доля ошибок, кнопка «Тренировать» → `/constructor?tag=<тег>`).
- `lib/ui/statistics/statistics_waveform.dart`, `heatmap_painter.dart` — painter'ы на токенах темы.
- `SessionConstructorScreen`: параметр `preselectedTag`, предвыбор тега в конфиге (спека A6.5/A6.7).
- Проверка: widget-тесты данных (проценты, подписи, кнопка «Тренировать» передаёт тег), пусто/ошибка/ретрай,
  конструктор с `?tag=`; widget-тест painter'ов не падает при нулевых/больших значениях.

### 5. Экран «Настройки» A6.6

- `lib/ui/settings/settings_screen.dart`: блоки
  - «Внешний вид»: тема (Светлая/Тёмная/Системная), dynamic color, анимация
    (Выразительная/Стандартная), шрифт для дислексии, размер шрифта (ползунок), контраст;
  - «API»: 4 провайдера со статусом ключа, «Добавить ключ» → экран настроек генерации,
    «Проверить» → реальный минимальный запрос (ADR-019), модель по умолчанию (каталог
    `kGenerationModels`), токены за неделю;
  - «Обучение»: желаемое удержание 0.70–0.95, шаги обучения (список: добавить/удалить 1–60 мин),
    дневные лимиты новых/повторных;
  - «Доступность»: haptics (контраст и размер — в «Внешнем виде», чтобы не дублировать элементы);
  - «О приложении»: версия, лицензии (`showLicensePage`), политика приватности (системный браузер).
- `lib/api/generation/api_key_verifier.dart`: проверка ключа минимальным запросом через существующие
  адаптеры/транспорт; наружу — только статус (`valid / invalidKey / missingKey / noConnection /
  rateLimited / providerNotConfigured / unexpected`), без ключей и тел.
- `lib/ui/settings/about_links.dart`: версия приложения и URL политики приватности.
- `docs/privacy.md` — политика приватности (публичный текст, ссылка из приложения).
- `assets/fonts/OpenDyslexic-Regular.otf` + лицензия OFL (SIL) — шрифт дислексии, только при включённом
  переключателе; `pubspec.yaml` fonts.
- Проверка: widget-тесты каждого блока (изменение → store, ошибка store → ARB-сообщение), проверка ключа
  на fake HTTP (валидный/401/сеть/нет ключа), лицензии/приватность (инжектированный лаунчер), версия
  совпадает с `pubspec.yaml` (тест-контракт).

### 6. Действие настроек на приложение

- `lib/ui/app.dart`: `ConsumerWidget`; `themeMode`, `contrastLevel` (контраст), dynamic color
  (`DynamicColorBuilder`, fallback на seed), шрифт дислексии, `MediaQuery.textScaler`, `M3ETheme`.
- `lib/domain/scheduling/scheduler.dart` и `app_providers.dart`: `schedulerProvider` собирает
  `FsrsScheduler(desiredRetention, learningSteps)` из настроек.
- `lib/domain/review/review_queue.dart` + движки классики/ленты: дневные лимиты (0 = без лимита);
  экраны передают значения настроек; конструктор не ограничивается (у него свой лимит).
- `lib/ui/review/review_card_view.dart` / `feed_progress_bar.dart` / экраны: motion
  («Стандартная» → стандартная пружина и без пульса) и haptics (выключено → нет платформенных вызовов).
- `lib/ui/generation/generation_screen.dart`: модель/провайдер по умолчанию из настроек.
- Проверка: integration-тест production-графа (настройки → scheduler: интервалы меняются; лимиты →
  очередь), widget-тесты haptics on/off на платформенном канале, motion-режим, тема/масштаб текста.

## Критерии приёмки итерации (сверка со SPEC)

1. A6.1: оболочка с `NavigationBar`/`NavigationRail`, пункты «Колоды/Статистика/Настройки», «Сессия»
   скрыта без активной сессии — **выполнено**, если widget-тесты обеих раскладок зелёные.
2. A6.5: удержание, тепловая карта года, слабые темы + «Тренировать» с тегом, прогноз 7 дней,
   недельный прогресс — **выполнено**, если data- и widget-тесты зелёные и блоки есть на экране.
3. A6.6: все перечисленные блоки, подписи из ARB, ни одной мёртвой кнопки — **выполнено**, если
   каждый элемент меняет `app_settings` и применение проверено тестом.
4. Настройки влияют: тема/размер/контраст/шрифт/динамический цвет (код), haptics, motion, retention,
   шаги обучения, дневные лимиты, модель по умолчанию — **выполнено** по тестам применения.
5. API: «Проверить» выполняет запрос и маппит ошибки в ARB; ключи не логируются и не попадают в БД —
   **выполнено** по fake-HTTP тестам и guard `no_secrets`.
6. Данные: схема БД не меняется (`schemaVersion=1`), миграций нет; статистика только читает
   `review_logs`/`cards`/`generation_jobs`.
7. Гейты: полный прогон, `analyze` 0, `dart format` 0 changed, покрытие ≥ 80 %, guard-тесты, сборка
   Windows — **выполнено** командами в сессии.

## Риски и как снимаем

- **Динамический цвет/шрифт на реальной ОС** — код и тесты в сессии; реальная ОС/рендер → L6c/L43.
- **Крупный экран настроек** — блоки выносятся в отдельные виджеты (`lib/ui/settings/widgets/`),
  в widget-тестах helper `scrollTo`, первичные действия не прячем в конце списка.
- **Ошибки записи настроек** — не глотаем: сообщение из ARB и повтор; состояние UI не «врёт».
- **Статистика на больших БД** — запрос за 365 дней и агрегация в Dart; объём и память — L44.
- **Регрессия существующих тестов** — маршрут настроек и иконка на «Колодах» меняются осознанно по
  SPEC A6.1; правки тестов фиксируются в журнале.
- **Коverage** — каждый новый файл получает тесты; исключений из покрытия не добавляем.
