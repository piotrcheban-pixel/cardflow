# Итерация 7.5 — красная фаза (диагностика бага с ключом)

**Дата:** 2026-11-14.

## D1 — ключ не сохраняется (воспроизведено тестом)

Тест: `test/widget/settings/generation_settings_key_bug_test.dart` («ключ сохраняется, даже когда
адрес и модель не заданы»). Сценарий владельца: ввести ключ DeepSeek → нажать «Сохранить».

Вывод падающего теста (assertion-level):

```
Expected: 'sk-deepseek-key'
  Actual: <null>
   Which: not an <Instance of 'String'>
ожидалось: ключ записан в защищённое хранилище (writeCalls=1), получено: writeCalls=0
```

**Причина.** `GenerationSettingsScreen._save()` сначала валидирует адрес сервера и модель и при
пустом/некорректном адресе делает ранний `return` — ключ до `ApiKeyStore` не доходит. На экране
нет каталога провайдеров, поэтому DeepSeek вводится как «OpenAI-совместимый сервер», где ключ
неотделим от адреса и модели. Ровно симптом владельца: «ввёл ключ, нажал Сохранить, ключ не
сохранился».

## D2 — генерация по умолчанию уходит не туда

`GenerationScreen._defaultProvider`: сначала облачные провайдеры с ключом (OpenAI → Gemini →
Anthropic), затем `openaiCompatible` **только если заданы и адрес, и модель**. Если сохранён
лишь ключ (или адрес/модель не сохранились из-за D1), выбирается OpenAI без ключа →
«Ключ не задан», генерация не работает.

Дополнительно: в `GenerationScreen` статус ключа совместимого провайдера жёстко `true`
(`configured[openaiCompatible] = true`) — экран не может сообщить, что ключа нет.

## D3 — «Сохранено» без проверки записи

`_save()` делает read-back (`storedKey`), но сообщение `settingsSaved` показывается независимо от
результата: если платформа молча потеряет значение, пользователь увидит «Сохранено».
Исправление — отдельное сообщение об ошибке проверки записи + Windows integration-тест на
реальном `flutter_secure_storage` (DPAPI).

## Что дальше

Лечение — не точечная правка, а рефакторинг провайдеров: аккаунт (каталог/пользовательский) с
собственным ключом в secure storage, единый экран списка, «+ Добавить провайдера», проверка
подключения; генерация берёт выбранный аккаунт. План — `journal/iteration-7.5/plan.md`.
