# Известные ограничения CardFlow

Формат: ограничение → причина → чем компенсировано в коде/тестах → когда снимается.
Каждое ограничение подтверждено фактом в текущей сессии; «проверено живьём» без доказательства не пишется.

## Окружение

| # | Ограничение | Причина | Компенсация | Снятие |
|---|---|---|---|---|
| L1 | Живые вызовы OpenAI / Gemini / Anthropic не проверялись | в окружении нет ключей API (проверено: present = нет) | mock/integration-тесты на адаптеры и пайплайн; live-тесты под тегом `live` и skip без ключей | когда владелец даст ключ |
| L2 | Сборки Android/iOS/macOS/Linux локально не выполняются | на хосте нет Android SDK/JDK, Xcode/macOS, Linux | CI-матрица (ubuntu/windows/macos); локально — `flutter build windows` при наличии VS-тулчейна | на соответствующих раннерах |
| L3 | CI фактически не запускался | нет git-remote на GitHub (репозиторий локальный) | workflow-файл создан и проверен статически | после создания GitHub-репозитория владельцем |
| L4 | Хуки `block-hardcoded-secret`, `block-destructive-command`, `confirm-git-push`, GateGuard не срабатывают | в конфигурации DSH-профиля хуки не подключены (проверено) | правила соблюдаются вручную; guard-тест `no_secrets_test.dart` | когда владелец подключит хуки |
| L5 | Навыки `tdd-workflow`, `dart-flutter-patterns`, `flutter-dart-code-review`, `material-3-skill`, `api-design`, `security-review`, `verification-loop`, `coding-standards` недоступны | в каталоге навыков сессии их нет (проверено) | работа по правилам `docs/agent-prompt.md` | когда навыки появятся в каталоге |
| L6 | Golden-тесты не прогоняются локально | стандартные шрифты Flutter не содержат кириллицы, golden-эталоны генерируются на Linux CI с явным шрифтом | тег `golden`, CI-шаг с Linux | на Linux CI |

## Продукт (перенесено из SPEC / ADR)

| # | Ограничение | Причина | Компенсация | Снятие |
|---|---|---|---|---|
| L7 | Форматы `.doc` / `.xls` не поддерживаются | нет зрелого Dart-пакета для чтения CFB (ADR-003) | понятное сообщение «Формат не поддерживается. Сохраните файл как DOCX или XLSX и попробуйте снова» | по решению владельца |
