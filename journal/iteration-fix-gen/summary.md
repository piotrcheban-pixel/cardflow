# Итог итерации fix-gen — «Исправление генерации»

**Дата:** 2026-11-15/16 · **Режим:** ИТЕРАЦИИ · **ADR:** ADR-029, ADR-030

## Что сделано

1. **Диагностика Д4/Д6** (`diagnosis.md`): подтверждена гипотеза JSON-
   экранирования LaTeX спайком `jsonDecode` (`\frac`→form feed, `\alpha`→
   `FormatException`); найдено, что одна карточка роняла весь фрагмент, а
   предпросмотр отказывался импортировать пак из-за одной невалидной карточки;
   зафиксированы факты `generation_jobs` реального приложения.
2. **Промпт `gen-ru-v5`** — дословно в `lib/api/prompts/system_prompt.dart`
   (raw-литерал) и `docs/prompts/gen-ru-v5.txt`; тест байт-в-байт. Пользовательское
   сообщение — строго `<materials> <wishes> <limit> <images>`, пустые блоки одной
   строкой, `Файл: <имя>` у каждого файла, каталог `<images>`
   (`id | файл | подпись | окружающий текст`).
3. **Схема + проекции + валидатор** (ADR-029): `image_id` в каноне и всех трёх
   проекциях; поштучная проверка схемы; правила `image_id`/`image_query`;
   `image_query` для абстрактных понятий обнуляется.
4. **Д1:** кнопка «Сгенерировать» неактивна без файлов и темы (подсказка ARB);
   имя колоды из темы; `source_excerpt` при пустых материалах → null;
   prompt-only без файлов работает и живьём.
5. **Д3:** изображения DOCX/PPTX/ODT с подписью/контекстом/слайдом; фильтры
   мусора (размер, пиксели, SHA-256 повторов); каталог только своего фрагмента;
   `image_id` → байты из файла до внешнего поиска; предпросмотр: убрать/заменить.
6. **Д2:** производный запрос из текста вопроса удалён; внешний поиск только по
   `image_query` модели; абстрактные понятия без картинок.
7. **Д4:** восстановление LaTeX до/после `jsonDecode`, нормализация `\(\)`/`\[\]`,
   `\$` не формула; `LatexText`/`ClozeText`/`InlineLatexText` рендерят формулы
   `Math.tex`, ошибка — предупреждение.
8. **Д6:** `GenerationFailureReason` (13 кодов) в `generation_jobs.error_code` и
   debug-лог; частичный импорт не блокируется упавшими фрагментами и невалидными
   карточками; «Фрагмент K из M: причина» + «Повторить неудавшиеся».
9. **Д5:** мягкие проверки качества (7 правил) и eval-набор из 3 сценариев;
   live-метрика доли пометок.
10. **Лимит карточек из пожеланий:** пропорциональное распределение по
    фрагментам, не больше запрошенного и не больше 20 на фрагмент.

## ADR итерации

- **ADR-029** — схема ответа модели `gen-ru-v5`: `image_id`, `image_query`,
  поштучная проверка, БД не меняется.
- **ADR-030** — изображения из документов, восстановление LaTeX, коды причин
  сбоя фрагментов, частичный импорт, удаление производного `image_query`.

## Не проверено / ограничения

L76 (изображения внутри PDF), L77 (EMF/WMF/SVG), L78 (ручные клики/скриншоты
владельца — GUI не автоматизируется), L79 (перечень причин в `error_code`),
L1 (OpenAI/Gemini/Anthropic живьём).

## Открытые вопросы владельцу

1. Нужна ли отдельная колонка/таблица причин сбоя фрагментов в БД (сейчас
   перечень в `generation_jobs.error_code`) — это изменение схемы, решает
   владелец.
2. Извлекать ли изображения из PDF (L76) — отдельная итерация с разбором
   XObject; сейчас PDF-сканы идут страницами PNG для Vision.
3. Pexels/Pixabay как источник картинок (L71) требуют ключа/решения владельца.
