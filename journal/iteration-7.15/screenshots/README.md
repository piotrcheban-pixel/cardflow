# Скриншоты итераций 7.14–7.16

Сняты golden-рендером реальных экранов (`tool/screenshots/screens_test.dart`,
запуск вручную с `--update-goldens`), 540×960 логических px при DPR 2
(1080×1920 PNG). Шрифт — Segoe UI (кириллица), иконки — MaterialIcons из
кеша Flutter; загружаются только локально, в CI не входят (`tool/`).
