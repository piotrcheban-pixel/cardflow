## Сделано

1. **Единый inline-рендер** — `latexTextSpans()`
   (`lib/ui/cards/content/latex_spans.dart`): текст + формулы
   (`$…$`, `$$…$$`, `\(…\)`, `\[…\]`) в одном `Text.rich`, все формулы сразу;
   стиль (цвет/кегль) наследует родителя, `fontSize`/`color` дозаполняются из
   темы (иначе `Math` падает на `fontSize!`). `InlineLatexText` переписан на
   нём; текст без формул остаётся обычным `Text` с `data`.
2. **`CardText`** (`lib/ui/cards/content/card_text.dart`) — единая точка
   «текст карточки вне карточки»: cloze → `ClozeText`, формулы →
   `InlineLatexText`, plain → `Text`; `style`, `textAlign`, `maxLines`,
   `overflow`, `revealed`.
3. **`CardContentView.showAllFormulas`** — вопрос режимов показывает все
   формулы сразу; cloze-пропуски по-прежнему скрыты (`revealed`).
4. **Переведены на `CardText`:** варианты «Теста» (semantic label — без `$`
   через `plainTextOfLatex`), утверждение и пояснение «Верно/Неверно», строка
   правильного ответа и `AnswerDiffView` «Ввода ответа», плитки «Подбора пар»,
   список ошибок итогов.
5. **Домен «Тест»** (ADR-034): `AnswerType.isChoice` + `AnswerTypes.isChoice`
   (короткий/число/**формула**, ≤ 120 символов) — формулу нельзя напечатать, но
   можно выбрать; `DistractorGenerator` и лист режимов используют `isChoice`,
   `isTypable` для «Ввода ответа» не изменился. `buildTrueFalseQuestion` берёт
   дистракторы из `isChoice` — формула в утверждении не выдаёт себя форматом.
   `classifyAnswer` относит `\(…\)`/`\[…\]` к `formula` (как `LatexMarkup`).
6. **Скриншоты** `journal/iteration-7.17/screenshots/`: «Тест» с формулами в
   вопросе **и в четырёх вариантах**, «Подбор пар», «Ввод ответа»,
   «Верно/Неверно». `tool/screenshots` теперь грузит KaTeX-шрифты
   `packages/flutter_math_fork/KaTeX_*` (иначе — квадраты Ahem).

## Ограничения

- Системный буфер/скринридер: формулы в semantic label читаются как текст без
  `$` (`plainTextOfLatex`), но не как математика.
- «Ввод ответа» по-прежнему не берёт формульные ответы (напечатать LaTeX
  нельзя) — L88/L87 не менялись.
- Diff посимвольный: для формульного ответа он не показывается (экран таких
  карточек не берёт), но виджет устойчив к LaTeX (обрывок остаётся текстом).
