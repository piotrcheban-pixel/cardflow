## 5. Ограничения

1. **L242 — «ровно N» в пределах плана.** Промпт v4 обязывает модель отдать
   весь бюджет партии, но бюджет строит `AllocationPlan`: у единицы не больше
   четырёх различимых слотов (`unit_id + angle`), а `unitCapacity` по богатству
   может быть меньше. Заказ сверх различимой ёмкости остаётся `materialLimited`
   и показывается числом («материала примерно на N карточек»). Аллокация в этом
   срезе не менялась: TASK ч. 1 — только промпт, а правка ёмкости меняет
   измеренную в S14–S16 семантику и требует отдельного замера (Q31).
2. **L243 — v4 не измерен живым прогоном.** TASK ч. 3 не выделяет бюджета на
   замер; сравнивать текст промпта «на глаз» с v3 запрещено (ADR-054 §1).
3. **Путь по умолчанию — legacy.** `auto` = legacy (`kGenerationPathV3MinUnits =
   null`): v4 — промпт пути v3, а не основание включать v3 по умолчанию.
   Решение о пути — по замерам S16–S17, не этим срезом.
4. **L241 не снят:** межпутевые «повторы» слепой выборки 17B остаются как были,
   новые выборки срез не собирает (TASK ч. 2 — только маскировка).
