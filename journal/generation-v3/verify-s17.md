## 2. Часть 1 — слепая выборка: `not_measured`, причина и что готово

- **Данные:** `live-s16/cells/*.json` несут только метрики — ключа `cards` в них
  нет; живые стенды до среза 17 карточки не сохраняли. TASK запрещает новые
  платные прогоны, поэтому 60 карточек взять физически не из чего.
- **Честный ответ:** `blind-sample-17.md` и `blind-key-17.json` записаны со
  статусом `not_measured` и причиной (`kBlindNoSavedCardsReason`). Вымышленные
  карточки в файл не попадают — это выдало бы вымысел за измерение.
- **Что готово к следующему замеру:**
  - `S12Bench` пишет карточки ячейки ключом `cards`
    (`BenchSavedCard.fromGeneratedCard`, 3 поля + unit/angle, без текстов
    материалов и ключей); стенд среза 16 обновлён — следующий прогон сохранит
    карточки обоих путей;
  - `buildBlindSample` (`lib/domain/generation/blind_sample.dart`) собирает
    30 + 30, перемешивает seed-ом, в выборке оставляет **только номер и тексты**
    (пути и id — в отдельном ключе); покрыт `blind_sample_test` (6: порядок,
    детерминизм, отсутствие пути в текстах, уникальность источника, недобор
    числом, `not_measured` без карточек);
  - `tool/blind_sample_s17.dart` пишет оба файла; после любого замера с
    сохранёнными карточками повторный запуск заполняет выборку без ручной
    работы.

**Разделение среза (TASK п. 88):** часть 1 распадается на «инструмент» (сделан
здесь) и «измерение» (S17B: замер с сохранением карточек + заполнение владельцем
+ расчёт доли годных — п. 8 TASK). Красная фаза задним числом не писалась:
инструмент покрыт тестами, а измерение честно помечено `not_measured`.

## 3. Часть 2 — правило выбора пути

- `GenerationPathMode { auto, v3, legacy }` вместо булева флага: JSON
  `generation_path_mode`, старый `generation_pipeline_v3` читается как `v3`/
  `legacy` (тесты `app_settings_pipeline_flag_test` 5/5). Значение по умолчанию —
  `auto`.
- Решение — `selectGenerationPath` (`generation_path.dart`): `auto` по порогу
  `kGenerationPathV3MinUnits`, ручные режимы — переопределение. Провайдер
  `generationPathDecisionProvider`/`generationUsesV3Provider` отдаёт решение
  пайплайну и экрану; настройка — три чипа «Авто / Новый путь / Прежний путь»
  (`ChoiceChip`, без литералов — ARB).
- **N\* данные не дают:** из оплаченных ячеек два объёма материала — 10 и 33
  единицы; v3 не выигрывает ни на одном (выигрыш требует одновременно
  `cleanRate` не ниже, `dupRate` не выше, `absoluteClean` не ниже legacy).
  Поэтому `kGenerationPathV3MinUnits = null`, решение несёт
  `boundaryNotDetermined`, авто = legacy. Правило «v3 для объёма ≥ N, legacy
  иначе» реализовано и проверено тестами с порогом (`path_rule_test`,
  `generation_path_test` 5/5).

## 5. Часть 3 — вердикт по выпуску

**Правило п. 10 по умолчанию не включается.** Причины (без «продолжаем
наблюдать»):
1. N\* не определён данными; авто честно остаётся на legacy.
2. Доля годных из слепой выборки не измерена (`not_measured`), поэтому условие
   п. 12 «доля годных v3 не ниже legacy» **не подтверждено** — при
   неподтверждённом условии v3 не включается автоматически.
3. v3 остаётся доступен ручным переопределением режима (не удалён, §9
   протокола), legacy — путь авто.

Расхождение, которое становится задачей S18: доля смысловых дублей v3 —
19,6–51,1 % на учебном тексте (до 8,3 % на статье). Промпт `gen-cards-v3` в этом
срезе не менялся (TASK «Не делать»), поэтому разница остаётся задачей на промпт,
а не на новый замер.

## 6. Гейты и красная фаза

- **Красная фаза (часть 0) — assertion-level:** `red-s17.txt` фиксирует
  `Expected: a numeric value within <1e-12> of <0.666…> Actual: <0.4>` (cleanRate
  от попыток) и `Expected: <0.4> Actual: <0.3076923076923077>` — **дубль двигал
  cleanRate**, то есть ровно тот дефект, который DoD части 0 запрещает.
- Новые модули (`generation_path`, `path_rule`, `blind_sample`) сначала не
  компилировались — нового API не было; это законная красная фаза для нового
  контракта (прецедент среза 16, часть 3), после появления API все тесты
  зелёные.
- `flutter analyze --no-pub lib test tool` → **No issues found!**
- `dart format --set-exit-if-changed lib test tool` → **0 changed** (747 файлов).
- `flutter test --no-pub --coverage --exclude-tags golden` → **3295 passed +
  20 skipped, exit 0** (`green-s17-full.txt`), покрытие рукописного кода
  **90,9 % (27463/30218)** при пороге 80 % (`coverage-s17.txt`); guards
  (`ru_strings`, `architecture`, `no_webview`, `no_secrets`, `contrast`,
  `ci_pdfium`) — зелёные в полном прогоне.
- Пересчёт ячеек — `dart run tool/recompute_matrix_s17.dart` → `matrix-s17.md`

  tool/blind_sample_s17.dart` → `blind-sample-17.md` + `blind-key-17.json`

## 7. Остаточные ограничения

1. L235 — N\* не определён: два материала, один провайдер (`deepseek/deepseek-flash`,
   L222), поведение модели меняется от замера к замеру.
2. L236 — объём материала для решения о пути до Understanding неизвестен;
   при появлении N\* его обязан передать вызывающий слой, иначе порог не начнёт
   работать.
3. L237 — слепая выборка `not_measured`: сохранённых текстов карточек нет, а
   платные прогоны TASK среза 17 запретил; инструмент готов, измерение — S17B.
4. `blockRate` у legacy — отброшенные проверкой, у v3 — жёсткие блокировки гейта
   (L234 не снят): в правило выбора не входит.
