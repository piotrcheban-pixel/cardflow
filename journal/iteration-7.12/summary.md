# Итерация 7.12 — итог «Фикс UX картинок, лимитов и поиска ИИ»

**Дата:** 2026-11-15 · ADR-028 · Owner-note: 3 критических UX-проблемы.

## Что было не так (по фактическим данным приложения)

1. **Дневной лимит.** `daily_new_limit=20`, за 15.11 выполнено **30** «новых»
   оценок; лимит считался по журналу дня, и только что созданный пак карточек
   (13 шт., 21:11) блокировался так же, как старые новые.
2. **Картинки у Basic.** Форма показывала изображение только для `basic` и при
   выборе картинки сразу создавала `OcclusionDocument()` → сохранение без масок
   падало. Домен и БД уже принимали медиа любого типа.
3. **ИИ и картинки.** Последнее задание (`deepseek-flash`, 13 карточек) пришло с
   `media_json = []`. Живой зонд показал: модель часто отдаёт `image_query: null`
   на определениях, Commons по русским словоформам даёт 0 файлов, Openverse
   таймаутит, ошибка поиска нигде не видна; DDG отвечает bot-challenge,
   Pexels/Pixabay требуют ключ.

## Сделано

- **ADR-028 §1:** изображение можно прикрепить к любому типу карточки; маски —
  необязательный переключатель (по умолчанию выключен). Домен:
  `CardDraft.primaryMediaId/hasImage`, `Card.primaryMediaId`; удаление/замена
  изображения, сохранение occlusion-карточек при выключении масок.
- **ADR-028 §2:** `ReviewQueue.build` всегда включает новые карточки,
  созданные в текущий локальный день; лимит новых действует для более ранних.
  Плюс предупреждение «Дневной лимит исчерпан» с «Продолжить без лимита»
  (`?limits=ignore`), «Тренировкой» и «Отменой» на экране колоды, в пустой
  классике и в ленте.
- **ADR-028 §3:** источники Commons → Wikipedia pageimages (ru → en) → Openverse;
  производный `image_query` для `basic`-определений (если модель не дала);
  запрет картинок в пожеланиях распознаётся; `CardIssueCode.imageNotFound` +
  предупреждение в предпросмотре; debug-диагностика пишет сырой ответ модели в
  консоль `flutter run`; бюджет поиска 90 с, Openverse 5 с.

## Доказательства

- Полный прогон: **1512 passed + 4 skipped** (до последнего микрофикса; финальный
  прогон — в `verify.md`), покрытие рукописного кода **92.4 % (10085/10914)**, analyze 0,
  format 0 changed.
- **Windows release** собран; **`flutter run -d windows`** — окно открылось без
  ошибок старта.
- **Windows-смоук** (`integration_test/session_smoke_windows_test.dart -d windows`):
  Basic+картинка без масок через реальную форму → `media`+файл; исчерпанный
  лимит не блокирует сегодняшнюю карточку и показывает иллюстрацию; старая
  карточка даёт предупреждение и «Продолжить без лимита»; генерация с
  `image_query` → картинка в предпросмотре → файл в `media`.
- **Живые тесты:** 7 passed на `deepseek-chat` (сырой ответ с `image_query=3`,
  Wikipedia 239 КБ, Commons 97 КБ, PDF-скан 3 стр. → 2 карточки).
- **Модель владельца `deepseek-flash`:** prompt-only `image_query=3`;
  production-пайплайн → **3 карточки, 3 картинки** (218 / 458 / 134 КБ JPEG).
- Правки ревью: предупреждение считает только выбранные карточки (тест),
  ru-guard (латиница в строке), фикстура generation_flow.
