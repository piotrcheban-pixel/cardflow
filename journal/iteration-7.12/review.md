## Проверено, замечаний нет

- **Слой домена без Flutter:** `ReviewQueue`, `image_query` — чистые функции,
  зависимости только `CardType`/`DailyLimits`; границы локального дня — тот же
  расчёт, что и расход дня.
- **Данные:** схема БД, `schemaVersion`, `format_version` не менялись; медиа
  обычной карточки пишется той же транзакцией `DriftCardRepository`; удаление
  изображения удаляет строку `media` и файл (тест).
- **Проводка `app_providers`:** `cardImageFinderProvider` = Commons → Wikipedia →
  Openverse; `generationDiagnosticsProvider` — sink `debugPrint` только в debug;
  `generationRunnerProvider` получает новый composite (интеграционный тест
  production-графа зелёный).
- **UX лимита:** диалог и пустое состояние имеют кнопки «Продолжить без лимита»,
  «Тренировка», «Отмена»; `?limits=ignore` не отключает запись FSRS, только
  лимиты; тесты classic + feed + deck.
- **Ошибки не проглатываются:** `imageNotFound` в предпросмотре + предупреждение;
  пустой поиск/ошибка сети/бюджет — все пути ставят пометку, кроме случая
  отключённого поиска/запрета пользователем (тест).
- **Секреты:** ключ не выводится; диагностика редактирует `sk-…`, `Bearer`,
  `AIza…`; тела запросов не логируются; `no_secrets` guard зелёный.
- **Guard-тесты:** architecture/ru_strings/no_webview/no_secrets — полный прогон
  зелёный.
- **Форматирование/анализатор:** 0 changed, 0 issues.
