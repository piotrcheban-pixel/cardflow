# CardFlow — пакет редизайна «Nocturne»

Документы дизайн-системы и дорожная карта редизайна визуального слоя Flutter-приложения CardFlow (интервальное повторение, FSRS). Это документация, а не код: в репозитории нет сборки и нет кода, который можно запустить.

- `REDESIGN-SPEC.md` — токены, стекло, движение, тактильный отклик, компоненты, экраны.
- `REDESIGN-PLAN.md` — пять этапов внедрения и зоны файлов.
- `DSH-PROMPTS.md` — промпты для агента-разработчика.

Технологии целевого приложения: Flutter (FVM), Riverpod 3, GoRouter, drift, `material_ui`.
Просмотр: открыть файлы в любом Markdown-просмотрщике.

## Дорожная карта
Этапы 1–5 из `REDESIGN-PLAN.md` реализует агент-разработчик в репозитории приложения.
