# AGENTS.md

Репозиторий содержит только документацию редизайна CardFlow «Nocturne» на русском языке.

- `REDESIGN-SPEC.md` — источник правды по визуалу. Значения HEX проверены на контраст по WCAG; при правке пересчитывайте контраст.
- `REDESIGN-PLAN.md` — этапы и зоны файлов (Красная зона — логика, менять её нельзя).
- `DSH-PROMPTS.md` — промпты; блок 0 вставляется в каждую сессию.

Соглашения: ключи, отмеченные 🔑, — контракт с тестами приложения, их нельзя переименовывать. Пользовательские строки — только через ARB. WebView и `google_fonts` запрещены. Дизайн-решения, которые расходятся с исходным SPEC.md, фиксируются в ADR-035.
